Project Development

Publication Roadmap

From a living GitHub framework to an accessible public resource and, eventually, a stable citable scholarly artifact.

Phase 1 — Research foundation

Complete
  • Core thesis and conceptual architecture
  • Research tracks and questions
  • Initial institutional bibliography
Next
  • Expand peer-reviewed bibliography
  • Create annotated literature review
  • Add inline citations where required
  • Continue separating evidence from HFAF propositions

Phase 2 — Public website

Build a nontechnical entry point for faculty, researchers, students, practitioners, and the general public.

Status: live and under active refinement.

Phase 3 — First public essay

The Human Remains
AI Should Shorten the Distance Between Thought and Action — Not Replace the Human in Between

Targets: HFAF website, Medium, and a LinkedIn adaptation.

Phase 4 — Downloadable faculty materials

  • Faculty Guide
  • Human–AI Course Design Canvas
  • What Should Remain Human? facilitator guide
  • Workshop participant workbook
  • Human–AI Use Spectrum one-page reference
  • AI-use reflection worksheet
  • Assessment redesign worksheet

Phase 5 — Pilot and evidence

  • Recruit an initial faculty pilot
  • Document teaching context and pre-implementation problem
  • Track which HFAF tools are used
  • Collect structured faculty feedback
  • Document assessment redesign decisions, resistance, failures, and unintended effects
  • Revise the framework based on evidence

Phase 6 — v1.0 scholarly release

Do not rush the DOI merely to have one. The DOI should represent a meaningful stable version of the framework.

  • Complete core framework and higher-education package
  • Complete research review and verify citations
  • Complete downloadable materials
  • Confirm authorship metadata and rights strategy
  • Add versioning policy and changelog
  • Tag GitHub release v1.0.0

Phase 7 — DOI / archival record

Proposed pathway: GitHub release → Zenodo archival record.

Phase 8 — Scholarly paper

Working direction: Human First, AI Forward: A Human-Agency Framework for Generative AI in Higher Education.

North-star criterion: Technology should increase human capacity without decreasing human agency.
