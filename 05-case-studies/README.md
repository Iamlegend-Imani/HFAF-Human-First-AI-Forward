# Case Studies

This section will document real-world implementations of Human First, AI Forward.

The purpose is to move the framework from proposition to practice and eventually to evidence.

## Case-study template

Each implementation should document:

- Context and discipline
- Participants
- Existing AI policy or practice
- Human capability being protected or developed
- Intervention
- AI-use mode
- Measures or observations
- Faculty/student response
- Unexpected outcomes
- Limitations
- Changes made to the framework
- Follow-up questions

No implementation should be presented as evidence of effectiveness beyond what the data can support.
